# hxwl-11 老花渐进镜 · 试戴登记台

首次配渐进镜顾客的试戴登记：双眼远用处方、下加光、镜架瞳高、试戴时长与远/近切换不适分全流程留痕。

## 本地运行

```bash
npm install
npm run dev      # 开发，端口 5111
npm run build    # 类型检查 + 生产构建
```

## 业务规则

每位顾客分左右眼保存：**远用球镜(DS)、远用柱镜(DC)、轴位(°)、下加光(ADD)、瞳高(mm)**，
以及**试戴时长**和**看远/看近切换不适分（0–5）**。

拦截与放行：

- 下加光越过 **0.75–3.00D** 区间 → 自动置「待复核」；
- 瞳高偏离镜架中心（镜架高度 ÷ 2，自底部起）**超过 4mm** → 自动置「待复核」；
- 不适分 **≥4** → 「已暂停」，须按医生意见调整参数并重新试戴至 4 分以下；
  暂停标记粘性保留，降分后仍转「待复核」，医生写调整意见才能确认；
- 字段未填全时确认按钮禁用并列出缺失项。

确认与版本：

- 首次确认生成 **v1 快照**；已确认档案参数只读，改参数必须点「改参数另存版本」进入改版，
  重新试戴、填写**改版原因**后另存 v2、v3……，旧版本始终可查，变更字段与原值高亮对照。
- 放弃改版会把工作区恢复到最新已确认版本。

持久化：

- 全部数据（顾客、待复核/暂停状态、版本历史）保存在浏览器 `localStorage`，
  关掉页面再打开仍在；首次打开自动带 3 条演示数据（暂停 / 待复核 / 已确认含历史版本）。

## 技术栈

React 19 + Vite + TypeScript + CSS，无后端、无第三方运行时依赖。

- `src/types.ts` — 数据模型与规则常量
- `src/rules.ts` — 待复核/暂停判定、确认拦截、版本快照
- `src/storage.ts` — localStorage 读写、旧数据迁移、演示数据
- `src/components/` — 顾客列表、试戴表单、版本历史
